# Attribution and reuse

## NASA T-MATS

The gas-turbine template and its derivatives originate from NASA's Toolbox for the Modeling and Analysis of Thermodynamic Systems (T-MATS): https://github.com/nasa/T-MATS.

The local installation was labeled v1.3.3. The original upstream commit was not recorded; do not infer an exact commit from that folder label. The local upstream Apache 2.0 license is preserved in [third_party/TMATS-LICENSE.txt](third_party/TMATS-LICENSE.txt). Existing notices in models and source snapshots are retained. GPT, RLS, DOB and PTO variants and supporting study scripts were developed/modified during this study in September 2026; the baseline GPT template is described in its usage guide.

Reference: J. W. Chapman et al., *Toolbox for the Modeling and Analysis of Thermodynamic Systems (T-MATS) User's Guide*, NASA/TM-2014-216638, 2014: https://ntrs.nasa.gov/citations/20140012486. The manual describes an earlier version; installed blocks determined actual behavior.

## Other dependencies and publications

MATLAB, Simulink and the System Identification Toolbox are separate MathWorks dependencies and are not distributed here. Installed runtime packages, fonts, simulation build caches, downloaded thesis/article PDFs, extracted reference text and temporary PDF renderings are excluded. Literature references, including Volkan Aran's thesis, are identified in the reports; consult their original sources for reuse terms.
